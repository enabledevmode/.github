Hi, I'm Izzy, a software developer. Enable Dev Mode is about building practical development skills you can actually use, whether that's landing a better job, leveling up at the one you have, or building and selling apps of your own.

Right now: building complete apps with Blazor and .NET, using the patterns and features the framework recommends today. This organization holds all the code behind it.

## What's here

| Repository | What it is |
| --- | --- |
| [IzzyBlazor](https://github.com/enabledevmode/izzyblazor) | The channel's own Blazor component library. Static server-side rendering first, and it works with JavaScript turned off. MIT licensed, in alpha, and built in public. |
| [enabledevmode.com](https://github.com/enabledevmode/enabledevmode.com) | The website: a Blazor Web App on .NET 10, static server-side rendering only, built entirely with IzzyBlazor, so it doubles as the library's working example. |
| Project repos | One per video project, named after the project's slug. Each one follows a complete app from the first commit to deployment, with the lessons as its commit history. The first arrives with the first project video. |

## Try IzzyBlazor

[![NuGet](https://img.shields.io/nuget/vpre/IzzyBlazor?label=IzzyBlazor&color=005AB6)](https://www.nuget.org/packages/IzzyBlazor)

```bash
dotnet add package IzzyBlazor --prerelease
```

It's early, so expect breaking changes between alpha releases. Progress is logged in The Blazor Roundup.
